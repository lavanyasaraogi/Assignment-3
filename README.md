# Lab 3 - Responsive Personal Portfolio Website

## Description
This project is an improved version of my Lab 2 portfolio.
It uses modern CSS features including Flexbox, Grid,
animations, hover effects and responsive design.

## Files
- index.html
- style.css

## Features
- Responsive navigation bar
- Hero section with animated text
- About section
- Technical skills grid
- Project cards
- Contact form
- CSS animations and hover effects

## Responsive Breakpoints

1. Desktop: Above 900px
2. Tablet: 601px to 900px
3. Mobile: 600px and below

## CSS Concepts Used
- Flexbox
- CSS Grid
- Media Queries
- Relative Units
- CSS Animations
- Hover Effects
- Transitions

## How to Run
1. Download the repository.
2. Open the folder in VS Code.
3. Open index.html using a browser or Live Server.
4. Resize the browser to test responsiveness.
